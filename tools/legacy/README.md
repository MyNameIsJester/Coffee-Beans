# Công cụ cũ (không còn dùng)

Các script này phục vụ giai đoạn website còn là các trang HTML tĩnh:

- `sync_header.ps1`, `replace_links.ps1`: chép/thay header và liên kết vào từng trang. **Không chạy lại**: header hiện được vẽ bằng `js/ui.js`, chạy lại sẽ ghi đè các trang đã cập nhật.
- `download_images.py`, `update_images.py`: tải/gán ảnh sản phẩm lúc ban đầu. Đường dẫn ảnh hiện nằm trong `js/seed.js` và `images/`.

Giữ lại để tham khảo, có thể xóa nếu không cần.
