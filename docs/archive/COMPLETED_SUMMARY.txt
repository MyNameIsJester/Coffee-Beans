🎯 8 MODULES QUẢN TRỊ
────────────────────────────────────────────────────────────────────────────

1️⃣ TỔNG QUAN (Dashboard)
   ├─ 4 stat cards (Khách, Sản phẩm, Đơn, Doanh thu)
   ├─ Bảng đơn hàng gần đây
   └─ Overview dashboard

2️⃣ QUẢN LÝ NGƯỜI DÙNG
   ├─ Danh sách khách hàng
   ├─ Xem thông tin
   ├─ Reset mật khẩu
   └─ Khóa/Mở khóa tài khoản

3️⃣ QUẢN LÝ LOẠI SẢN PHẨM
   ├─ Thêm loại mới
   ├─ Sửa loại
   ├─ Xóa/Ẩn loại
   └─ Hiển thị số sản phẩm

4️⃣ QUẢN LÝ SẢN PHẨM
   ├─ Danh sách sản phẩm
   ├─ Thêm (Mã, Tên, Loại, Hình, Mô tả)
   ├─ Sửa (Thông tin hiển thị sẵn)
   ├─ Xóa/Ẩn sản phẩm
   └─ Hiển thị: Giá vốn, giá bán, tồn kho

5️⃣ QUẢN LÝ NHẬP HÀNG
   ├─ Danh sách phiếu nhập
   ├─ Thêm: Ngày, sản phẩm, SL, giá
   ├─ Sửa phiếu (chưa hoàn thành)
   ├─ Hoàn thành phiếu
   └─ Xóa phiếu

6️⃣ QUẢN LÝ GIÁ BÁN
   ├─ Tỉ lệ lợi nhuận theo loại
   ├─ Tỉ lệ lợi nhuận theo sản phẩm
   └─ Tra cứu: Giá vốn → % Lợi → Giá bán

7️⃣ QUẢN LÝ ĐƠN HÀNG
   ├─ Danh sách đơn hàng
   ├─ Tìm kiếm theo ID
   ├─ Lọc theo trạng thái
   ├─ Xem chi tiết
   └─ Cập nhật trạng thái (Mới, Xử lý, Giao, Hủy)

8️⃣ QUẢN LÝ TỒN KHO
   ├─ Tra cứu số lượng tồn
   ├─ Cảnh báo sắp hết hàng
   ├─ Thống kê: Nhập - Xuất - Tồn
   ├─ Theo loại sản phẩm
   └─ Theo thời gian
